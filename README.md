# Implementation of the Conflict-Based Search (CBS) Algorithm for the Multi-Agent Path Finding (MAPF) Problem

## CBS Algorithm

Conflict-Based Search (CBS) is a hierarchical algorithm designed for solving the Multi-Agent Path Finding (MAPF) problem. The algorithm operates on two levels: a low level and a high level.

The low level independently computes a path for each agent using the A* algorithm with the Manhattan distance heuristic. The high level detects collisions between agents and incrementally builds a constraint tree that introduces additional constraints to eliminate conflicts between paths.

This approach allows CBS to efficiently find collision-free solutions while preserving optimality for individual agent paths.

---

## Files

- `lowLevel.py`  
  Contains the implementation of the low-level search. It uses the A* algorithm to compute a path from the start node to the goal node for an individual agent while respecting constraints generated by the high level.

- `highLevel.py`  
  Contains the `ConstraintTree` class responsible for the high-level CBS logic. It detects conflicts between agents, generates constraints, and repeatedly calls the low-level search until a collision-free solution is found.

- `grid.py`  
  Implements the object-oriented representation of the environment grid and provides utility functions for neighbour generation and obstacle handling.

- `testExamples.py`  
  Contains a collection of predefined test examples that can be used without manually creating custom scenarios.

- `animate.py`  
  Provides a graphical user interface (GUI) for visualizing the movement of agents and animating the resulting paths step-by-step.

- `createMaze.py`  
  Contains helper functions for easier creation of custom mazes and obstacle layouts.

- `main.py`  
  The main program entry point that initializes the problem, runs the CBS algorithm, and launches the visualization.
